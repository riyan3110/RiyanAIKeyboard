# In-keyboard settings overlay

The settings gear opens a tabbed settings panel inside the IME instead of launching the app activity. The keyboard stays available underneath so text fields such as API keys, model names, URLs, custom colors, and writing samples can still be edited directly.

The panel provides Model AI, Memori Gaya, Tema & Tampilan, and Ketikan & Saran tabs. Changes are staged until **Simpan & Terapkan** is pressed; **Reset Bawaan** only resets the staged values until they are saved.
